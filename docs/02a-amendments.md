# 02a - Protocol amendments and deviations (dated; each says what was known when it was made)

Protocol v1.0 (02-design.md) was written 2026-10-17 before any search or screening. The amendments below were made on 2026-10-17 during the same session; none was made after trend or compliance results were seen unless stated.

- A1 (made after screening, before extraction). Search sources: OpenAlex keyless cursor paging is refused without an API key, so the OpenAlex search used page-number paging (<= 8 pages x 100 per query family). Semantic Scholar answered HTTP 429 for 4 of 6 queries (2 queries returned 100 records each). Google Scholar returned results to plain fetches for the 12 planned queries x 2 pages (no block encountered, none circumvented). Shodhganga was searched with 11 queries x up to 3 pages. Crossref: 23 queries x 2 pages (relevance-ranked, no abstracts, so Crossref records were screened on title only).
- A2 (made after screening). Screening was by fixed keyword rule followed by manual title reading of the 547 records the rule flagged (single screener). The rule thresholds were fixed in 02-design.md; the manual step used the same criteria.
- A3 (made while extracting, before any trend/compliance output). Official sources were added beyond the protocol list because they were found to be open and machine-readable: the OpenCity mirror of KSPCB monthly lake reports (28 PDFs, Jul 2023 - Nov 2025), CPCB NWMP annual lake/pond/tank tables 2013-2024 (cpcb.gov.in), and the 2011 results CSV hosted by OpenCity (publisher listed as the Department of Mines and Geology). India-WRIS and data.gov.in were checked: no Bengaluru lake water-quality table was found there (India-WRIS home page opened; data.gov.in search page returned only a JavaScript shell). The Lake Development Authority site (ldabangalore.gov.in) could not be reached (no response).
- A4 (made after seeing that CPCB 2023-24 annual ranges lie 99.5-100% inside the KSPCB monthly values for the same station codes, before any trend test was run). CPCB NWMP and KSPCB monthly data are not independent (CPCB tables for Karnataka are compiled from the state board's monitoring). The protocol's trend-eligibility rule ("at least two independent sources") is therefore replaced for official series by: one official source, >= 7 annual points spanning >= 8 years (CPCB 2016-2024). Trends from KSPCB monthly data (27 months) are reported as short-window exploratory only. Literature series never met any version of the rule.
- A5 (made before trend tests). Pre/post-2017 comparison was possible only for Ulsoor (CPCB station 1388: 3 annual values up to 2016, 7 from 2018). Bellandur and Varthur have only 2016 and 2017 values before the foaming-era orders, so the comparison could not be run for them.
- A6 (data quality). Two papers whose tables show implausible values (L290: DO 21-36 mg/L, repeated digits; L441: pH 16.00 +/- 27.71, humidity as a water parameter) were excluded at full text (reason X8, listed in the screening log) rather than loaded and flagged. This adds exclusion code X8 usage for "data-quality exclusion" which the protocol listed only as "other".
- A7 (extraction coverage). The protocol aimed to extract every reported measurement from all included studies. In this pass 20 published studies plus 2 grey/official-report sources (DMG 2011 CSV; IISc blueprint Table 3.1) and the KSPCB/CPCB series were extracted. 30 further eligible full texts were retrieved and queued; 111 retrieved full texts were negative on an automated triage (not read by eye); 167 candidates had no obtainable open full text. This is a limitation, not a finding about the literature.
- A8 (Aug 2023 KSPCB file). The Aug 2023 monthly PDF has no extractable table layer and was not parsed; the Mar and Feb 2024 files were found to carry swapped month labels in the OpenCity titles (document titles say Feb/Mar respectively) and were relabelled from the in-document titles.
